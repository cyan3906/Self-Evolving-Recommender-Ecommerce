## The recommender is no longer static.

### Recommend → Interact → Reflect → Evolve → Retrieve → Recommend Again

**Every interaction becomes experience.**
**Every experience becomes strategy.**
**Every strategy makes the Agent smarter.**

<br>

### 🧠 What happens when the recommendation works?

```text
User buys the product
        ↓
Agent identifies WHY it worked
        ↓
Successful strategy is extracted
        ↓
Strategy is stored in long-term Skill Memory
        ↓
Similar scenario appears
        ↓
Agent automatically retrieves the strategy
        ↓
🎯 Better recommendation
```

### 💀 What happens when it fails?

```text
User ignores the recommendation
        ↓
Agent analyzes WHY it failed
        ↓
Failure pattern is recorded
        ↓
Strategy is corrected / evolved
        ↓
The same mistake is less likely to happen again
```
